# CoE LootSplit Bot

This project is a Python 3.12 Discord bot.

## Run

Start the `Discord Bot` workflow, which runs:

```sh
python bot.py
```

## Required secrets

- `TOKEN`: Discord bot token
- `GOOGLE_SCRIPT_URL`: deployed Google Apps Script web-app endpoint used by the bot

The bot requires Discord's Message Content and Server Members privileged intents to be enabled for its application.
